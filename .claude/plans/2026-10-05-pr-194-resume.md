### 1. One retry policy in the loader, for icon, logo and flag

Round-3 findings it closes: a failed flag never re-renders, so it stays blank on an untouched field
(`mud-phone-input.tsx:407`); opening the list no longer retries at once (`:771`); `Date.now()` is not
monotonic (`:415`); `warnedFlags` never cleared on success (`:416`); `mud-icon` / `mud-logo` never retry
after an offline failure (`svg-assets.ts:75`); the spec does not prove the warn dedupe (`spec.tsx:262`)
and hard-codes 10 000 (`spec.tsx:258`).

Design:
- `src/utils/svg-assets.ts`: the failure record becomes `{ kind: 'import' | 'rejected', message, at, attempts }`
  with `at = performance.now()`. Export `SVG_RETRY_MS = 10_000` (and a cap, e.g. 5 min) and give the
  loader `retryDelay(key): number` — remaining ms of an exponential backoff
  (`min(SVG_RETRY_MS * 2 ** (attempts - 1), cap) - elapsed`, floored at 0; `Infinity` for `'rejected'`,
  which no retry fixes) — and `clearFailures()`. `failure(key)` returns the record (callers read
  `.message`). A success deletes the record.
- `mud-icon` / `mud-logo`: on a failed load, warn once per failure streak (not on every retry), then
  `setTimeout(() => this.loadSvg(), icons.retryDelay(key))` unless the delay is `Infinity`; clear the
  timer on a name/variant change and in `disconnectedCallback`. `mud-logo` emits `reason: 'rejected'`
  for `kind === 'rejected'`, `'fetch-failed'` for `'import'`; union and JSDoc updated.
- `mud-phone-input`: `drawFlags` skips a key while `flagLoader.retryDelay(key) > 0` (replaces the
  component's own `Date.now()` map); after a failure it schedules ONE timer per instance for the
  smallest pending delay that bumps `flagLoads` (so a render happens with no user input); opening the
  list calls `flagLoader.clearFailures()` and retries at once; `warnedFlags` loses a key on success;
  clear the timer in `disconnectedCallback`.
- Specs: loader backoff, kinds, `clearFailures` (mock `performance.now`); icon and logo retry by
  capturing the `setTimeout` callback and its delay through a spy and invoking it; logo `'rejected'`;
  phone-input on `type="local"`: fails, timer fires, re-imports, draws, one warning — awaiting the second
  rejection's warning path before asserting the count, and importing `SVG_RETRY_MS` instead of `10_000`.
  Each guard is mutation-checked (remove it, the spec fails, restore).

### 2. An allowlist for attribute values in the generator

Round-3 findings it closes: `cursor="image-set('https://…' 1x)"` passes and Chromium requests it
(security, Medium, confirmed); `url(' "evil.svg#a')` and single-quoted escapes pass `forbiddenIn` on
raw markup (`build-asset-modules.mjs:63`, `:66`); `danglingReferences` misses `url(' #g')` (`:97`).

Facts (scan of the 522 committed drawings, 2026-10-05): every attribute value containing `(` is one of
`transform` (1104), `fill` (373), `mask` (89), `clip-path` (70), `gradientTransform` (27),
`marker-mid` (2); the only functions are `matrix` 666, `url` 534, `scale` 299, `translate` 226,
`rotate` 168, `skewY` 1; no attribute is single-quoted.

Design:
- `scripts/assets/svgo.asset-modules.mjs`: strip `cursor` (`removeAttrs` `(on.*|cursor)`).
- `scripts/assets/build-asset-modules.mjs`: parse every attribute (`\s([\w:-]+)=(?:"([^"]*)"|'([^']*)')`),
  refuse a value with a backslash, and for a value with `(` require every function call to be
  `url(#id)` (strict: `url\(\s*(['"]?)\s*#[A-Za-z_][\w.:-]*\s*\1\s*\)`) or one of `matrix`, `translate`,
  `scale`, `rotate`, `skewX`, `skewY`, `rgb`, `rgba`, `hsl`, `hsla`. Replace the url / backslash
  `FORBIDDEN` rows with this; keep the element and the other rows. `danglingReferences` reads its
  `url(#id)` ids through the same parse.
- Spec: the round-2/3 bypasses (`image-set`, `-webkit-image-set`, `u\72l(`, `url(' "x')`, single-quoted
  escape) each refused; `url( #g)` / `url('#g')` accepted and seen by `danglingReferences`; `--check`
  still exits 0.

`docker-install-probe.sh <repo> <outDir>` — the Dockerfile install layer without Docker:

```sh
#!/bin/sh
set -e
REPO="$1"; OUT="$2"
rm -rf "$OUT"; mkdir -p "$OUT"
awk '/^COPY \. \./{exit} /^COPY /{print}' "$REPO/Dockerfile" | while read -r _ rest; do
  set -- $rest; n=$#; eval "dest=\${$n}"
  i=1; while [ $i -lt $n ]; do eval "src=\${$i}"
    if [ -d "$REPO/$src" ]; then mkdir -p "$OUT/$dest"; cp -R "$REPO/$src/." "$OUT/$dest/";
    else case "$dest" in */|.) mkdir -p "$OUT/$dest"; cp "$REPO/$src" "$OUT/$dest/";; *) mkdir -p "$(dirname "$OUT/$dest")"; cp "$REPO/$src" "$OUT/$dest";; esac; fi
    i=$((i+1)); done
done
cd "$OUT" && yarn install --immutable --mode=skip-build > install.log 2>&1
```
