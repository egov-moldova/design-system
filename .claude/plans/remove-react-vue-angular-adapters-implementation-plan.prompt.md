# Remove React / Vue / Angular Adapters — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Delete the `angular-design-system/`, `react-design-system/`, `vue-design-system/` workspace packages and remove every reference to them from configs, scripts, docs, and Docker — leaving `@age/web-components` as the single supported adapter.

**Architecture:** Pure removal — no new code is written. Every place that mentions a framework adapter is either deleted outright or rewritten to point at `@age/web-components`. After completion the build graph contains only `build` and `build.web` (plus `demo.web`, tokens, storybook, etc.), and the published surface is `@age/design-system` + `@age/web-components`.

**Tech Stack:** Yarn 4 workspaces, Wireit, Stencil 4.43, Docker, Markdown.

---

## Context

`@age/web-components` (the vanilla HTML / JS adapter) has now been built, demoed (`yarn demo.web` → http://localhost:5174), and documented in [README.md](README.md). It registers every Stencil custom element via a single `defineCustomElements()` call and works with bundlers, plain HTML import maps, and TS type augmentation.

The three legacy framework adapters (`react-design-system/`, `vue-design-system/`, `angular-design-system/`) are now redundant. Keeping them around imposes carrying costs: extra dependencies, extra build pipelines, extra documentation, extra surface area in Stencil config, and the implication to consumers that those packages remain supported.

This plan retires the three adapters in one shot so the repo's posture matches the new direction: *one* design system, *one* adapter (`@age/web-components`), and *one* set of build commands. It is intentionally a separate plan from the `@age/web-components` introduction so the cleanup can be reviewed and merged with full confidence the vanilla path works.
