# Content Overlays

Fade overlays for scrollable content that indicate more content is available above or below.

## Usage

Apply the appropriate overlay class to your scrollable container based on the background color:

- **`.overlay--white`** - White fade for dark backgrounds
- **`.overlay--black`** - Black fade for light backgrounds

---

## `.overlay--white`

Use on **dark backgrounds** (black, dark gray, etc.) to create white fade gradients at the top and bottom edges.

### Example

<div style={{ marginBottom: '32px' }}>
  <div
    className="overlay--white"
    style={{
      height: '200px',
      overflow: 'auto',
      background: 'var(--color-background-base-inverse-default)!important',
      color: 'var(--color-text-base-inverse-default)!important',
    }}
  >
    <div style={{ height: '1000px', color: 'var(--color-text-base-inverse-default)!important' }}>
      <h3 style={{ marginTop: 0, color: 'var(--color-text-base-inverse-default)' }}>Scrollable Content</h3>
      <div>Duis aute irure dolor in reprehenderit in voluptate velit esse cillum dolore eu fugiat nulla pariatur.</div>
      <div>
        Excepteur sint occaecat cupidatat non proident, sunt in culpa qui officia deserunt mollit anim id est laborum.
      </div>
      <div>Sed ut perspiciatis unde omnis iste natus error sit voluptatem accusantium doloremque laudantium.</div>
      <div>
        Nemo enim ipsam voluptatem quia voluptas sit aspernatur aut odit aut fugit, sed quia consequuntur magni dolores.
      </div>
    </div>
  </div>
</div>

### Code

```html
<div class="overlay--white" style="overflow: auto; background: var(--color-background-base-inverse-default)!important;">
  <!-- Your scrollable content -->
</div>
```
