# Migrate Component to Production

## Step 1: Read Hidden Component

Read all files in `src/hidden/cor-{name}/` to understand current state:

- `cor-{name}.tsx`
- `cor-{name}.css`
- `cor-{name}.types.ts` (if exists)
- `cor-{name}.enums.ts` (if exists)
- `cor-{name}.constants.ts` (if exists)
- `cor-{name}.stories.ts` (if exists)
- `test/cor-{name}.spec.tsx` (if exists)

Also check if a token file exists: `tokens/core/components/{name}.tokens.json`

## Step 2: Gap Analysis

Compare the hidden component against the required file structure:

```text
src/components/cor-[name]/
├── cor-[name].tsx              # REQUIRED
├── cor-[name].css              # REQUIRED
├── cor-[name].types.ts         # Required if public types exist
├── cor-[name].enums.ts         # Required if enum props exist
├── cor-[name].constants.ts     # Optional
├── cor-[name].stories.ts       # REQUIRED
├── readme.md                   # Auto-generated by Stencil
└── test/
    └── cor-[name].spec.tsx     # REQUIRED
```

List missing files.

## Step 3: Run Full Audit

Invoke the `/audit-component` workflow against the hidden component.

This will identify all issues across:

- Structure, tokens, CSS, TypeScript, accessibility, security, performance, stories, tests

## Step 4: Fix All Critical and High Issues

Address every Critical and High severity issue from the audit report **before** migration.

Medium and Low issues can be tracked as follow-up tasks.

## Step 5: Ensure Token File

- [ ] Token file exists: `tokens/core/components/{name}.tokens.json`
- [ ] All token references are valid `{token.path}` syntax
- [ ] Dark mode overrides exist for color-related tokens

// turbo

```bash
yarn tokens.build
```

## Step 6: Ensure Test Coverage

Minimum test requirements before migration:

- [ ] Smoke test: renders without errors

- [ ] Prop reflection: attributes appear on host
- [ ] Event emission: custom events fire with correct payload
- [ ] Slot rendering: content appears in correct slots
- [ ] Disabled state: interaction blocked

## Step 7: Ensure Story Coverage

Minimum story requirements:

- [ ] `Default` story
- [ ] `AllVariants` story (if variants exist)
- [ ] `AllSizes` story (if sizes exist)
- [ ] `States` story (default, disabled, at minimum)

## Step 8: Move to Production

Move from `src/hidden/cor-{name}/` to `src/components/cor-{name}/`:

```bash
# Windows (PowerShell)
Move-Item -Path "src/hidden/cor-{name}" -Destination "src/components/cor-{name}"

# macOS / Linux (Unix)
mv src/hidden/cor-{name} src/components/cor-{name}
```

## Step 9: Update Exports

Check if `src/index.ts` needs updating to export the new component.

## Step 10: Full Verification

// turbo

```bash
yarn lint
```

// turbo

```bash
yarn test
```

// turbo

```bash
yarn sp.build
```

## Step 11: Human Approval Gate

**STOP** — present migration summary:

```text
## Migration Summary: cor-{name}

### Source: src/hidden/cor-{name}/ → src/components/cor-{name}/

### Files migrated:
- [list all files]

### Audit results:
- Critical fixed: X
- High fixed: Y
- Remaining medium/low: Z (tracked as follow-up)

### Verification:
- Lint: PASS/FAIL
- Tests: PASS/FAIL
- Storybook build: PASS/FAIL
```

Wait for approval before committing.
