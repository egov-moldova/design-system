# AGE Angular Design System

Angular wrapper for AGE Design System components built with Stencil.

> **📖 For complete documentation, see the main [README.md](../README.md) in the project root.**

## Quick Start

### Installation

```bash
yarn add @age/design-system @age/angular-design-system
```

### Basic Usage

**In `app.module.ts`:**

```typescript
import { NgModule } from '@angular/core';
import { BrowserModule } from '@angular/platform-browser';
import { DesignSystemModule } from '@age/angular-design-system';

@NgModule({
  imports: [
    BrowserModule,
    DesignSystemModule  // Automatically initializes web components
  ],
  bootstrap: [AppComponent]
})
export class AppModule { }
```

**In your templates:**

```html
<cor-button variant="primary">Click me</cor-button>
<cor-input [(ngModel)]="userName" label="Username"></cor-input>
```

## Features

- ✅ Full TypeScript typing and IntelliSense
- ✅ Angular Forms support (ngModel, FormControl, FormGroup)
- ✅ Automatic web component initialization
- ✅ Tree-shaking and lazy loading
- ✅ 7 wrapped components ready to use

## Development

This package is automatically generated by `@stencil/angular-output-target` from Stencil components.

### Rebuild After Component Changes

```bash
# In project root
yarn build.angular

# In angular-design-system
yarn build
```

### Available Scripts

- `yarn build` - Compile TypeScript to dist/
- `yarn copy:tokens` - Copy CSS design tokens from parent project
