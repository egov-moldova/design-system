# @egov-moldova/mud-angular

Angular adapter for the MUD Design System: typed standalone components and form value accessors around the `mud-*` custom elements of `@egov-moldova/mud`.

Not yet published. Install, `provideMud`, `MUD_FORM_ACCESSORS` and binding notes are in the root README under [Angular component wrappers](../../README.md#angular-component-wrappers). Contributor notes (builds, the consumer fixture) are in [CONTRIBUTING.md](../../CONTRIBUTING.md#framework-adapters-packagesreact-packagesvue-packagesangular).
