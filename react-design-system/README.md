# AGE React Design System

React wrapper for AGE Design System components built with Stencil.

> **📖 For complete documentation, see the main [README.md](../README.md) in the project root.**

## Quick Start

### Installation

```bash
yarn add @age/design-system @age/react-design-system
```

### Basic Usage

**In your React app:**

```tsx
import React from 'react';
import { CorButton, CorInput } from '@age/react-design-system';

function App() {
  const [userName, setUserName] = React.useState('');

  return (
    <div>
      <CorButton variant="primary" onClick={() => console.log('Clicked!')}>
        Click me
      </CorButton>
      
      <CorInput 
        label="Username" 
        value={userName}
        onCorChange={(e) => setUserName(e.detail.value)}
      />
    </div>
  );
}

export default App;
```

## Features

- ✅ Full TypeScript typing and IntelliSense
- ✅ React-friendly event handlers
- ✅ Automatic web component initialization
- ✅ Tree-shaking and lazy loading
- ✅ All AGE Design System components wrapped

## Event Handling

Stencil components emit custom events. In React, you can listen to them using the `on` prefix:

```tsx
<CorButton 
  onCorClick={(e) => console.log('Button clicked!', e.detail)}
>
  Click me
</CorButton>

<CorInput 
  onCorChange={(e) => console.log('Value changed:', e.detail.value)}
  onCorBlur={(e) => console.log('Input blurred')}
/>
```

## Development

This package is automatically generated by `@stencil/react-output-target` from Stencil components.

### Rebuild After Component Changes

```bash
# In project root
yarn build.react

# In react-design-system
yarn build
```

### Available Scripts

- `yarn build` - Compile TypeScript to dist/
- `yarn copy:tokens` - Copy CSS design tokens from parent project

## TypeScript Support

All components are fully typed. Import types directly:

```tsx
import type { Components } from '@age/react-design-system';

type ButtonProps = Components.CorButton;
```

## Styling

Import the design tokens CSS in your app:

```tsx
// In your main App.tsx or index.tsx
import '@age/design-system/dist/design-system/design-system.css';
import '@age/design-system/dist/design-system/tokens/core.tokens.css';
```
