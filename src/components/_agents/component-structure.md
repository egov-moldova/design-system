## File Structure

```text
src/components/cor-[name]/
├── cor-[name].tsx              # Component class
├── cor-[name].css              # Styles (PostCSS nested)
├── cor-[name].types.ts         # TypeScript interfaces, type aliases
├── cor-[name].enums.ts         # Enum values for props
├── cor-[name].constants.ts     # Static constants (allowed tags, etc.)
├── cor-[name].stories.ts       # Storybook CSF3 stories
├── readme.md                   # Auto-generated by Stencil
└── test/
    ├── cor-[name].spec.tsx     # Unit tests (newSpecPage)
    └── cor-[name].e2e.ts      # E2E tests (newE2EPage)
```

## TSX Class Member Order

1. `@Prop({ reflect: true })` — public props (with JSDoc, defaults, enums)
2. `@State()` — internal reactive state
3. `@Element()` — host element reference
4. `@AttachInternals()` — form internals (form elements only)
5. `@Event()` — custom events
6. `@Watch()` — prop watchers (if any; see rule below)
7. `@Listen()` — DOM event listeners
8. Lifecycle: `componentWillLoad` → `componentDidLoad` → `componentDidUpdate`
9. Private methods and private refs
10. `render()` — always last

### @Watch Rule

**Forbidden** for side effects or state cascades.

**Allowed** only for syncing native DOM properties without attribute equivalent:

```typescript
// ✅ ALLOWED — DOM property sync
@Watch('checked')
watchChecked(newValue: boolean) {
  if (this.inputElement) {
    this.inputElement.checked = newValue;
    this.inputElement.indeterminate = newValue;
  }
}

// ❌ FORBIDDEN — side effects
@Watch('value')
watchValue(newValue: string) {
  this.doApiCall(newValue);    // Use @Listen or lifecycle instead
  this.someOtherState = newValue;
}
```

## Host Class Management

### Declarative Pattern (REQUIRED)

For state-driven host classes, use the **declarative `getHostClasses()` pattern**:

```typescript
export class CorExample {
  @Prop({ reflect: true }) active: boolean = false;
  @Prop({ reflect: true }) disabled: boolean = false;

  // Internal state for interactive states
  private hovered = false;
  private focused = false;
  private pressed = false;

  @Listen('mouseenter')
  handleMouseEnter() {
    if (!this.disabled) {
      this.hovered = true;  // ✅ Update state, not classList
    }
  }

  @Listen('mouseleave')
  handleMouseLeave() {
    this.hovered = false;
  }

  // Helper method: derives classes from state
  private getHostClasses(): string {
    const classes = [];
    if (this.active) classes.push('is-active');
    if (this.hovered) classes.push('is-hovered');
    if (this.focused) classes.push('is-focused');
    if (this.pressed) classes.push('is-pressed');
    if (this.disabled) classes.push('is-disabled');
    return classes.join(' ');
  }

  render() {
    return (
      <Host class={this.getHostClasses()}>
        {/* content */}
      </Host>
    );
  }
}
```

### Benefits

- ✅ **Performance**: Classes computed once per render cycle (not on every event)
- ✅ **Declarative**: State → classes mapping is explicit and centralized
- ✅ **Maintainable**: Single source of truth for all state-to-class logic
- ✅ **Stencil Best Practices**: Leverages virtual DOM diffing instead of bypassing it
- ✅ **Consistent**: Matches pattern used in `cor-avatar`, `cor-column-action`

### Anti-Pattern (FORBIDDEN)

```typescript
// ❌ FORBIDDEN — imperative classList manipulation
@Listen('mouseenter')
handleMouseEnter() {
  this.host.classList.add('is-hovered');  // Bypasses virtual DOM
}

componentWillRender() {
  if (this.active) {
    this.host.classList.add('is-active');  // Side effects in lifecycle
  }
}
```

**Why forbidden:**

- Mutates DOM on every lifecycle call, even if state unchanged
- Bypasses Stencil's virtual DOM diffing
- Scattered logic across multiple methods
- Side effects in lifecycle methods

### When to Use `classList` Manipulation

Only for **external events** that don't trigger re-render (rare). For state-driven classes, always use `getHostClasses()`.

## stenciljs-component-development Skill Corrections

| Skill Says | Correct |
| --- | --- |
| `my-component` prefix | Always **`cor-*`** prefix |
| `@Prop({ reflect: true })` "use sparingly" | **Reflect most props** — variant, size, disabled, etc. |
| Member order: Element → State → Props | `@Prop` → `@State` → `@Element` → `@AttachInternals` → `@Event` → `@Watch` → `@Listen` → Lifecycle → Private → `render()` |
| No token integration | Always use CSS custom properties from tokens |
| No `::slotted()` patterns | Use `::slotted(*)` for slot-based components |
| No `:host([attr])` patterns | Use `:host([variant='x'])`, `:host([size='y'])` |
| Generic `@Event() itemSelected` | Use `cor` prefix: `@Event() corButtonClick` |
| No slot validation | Use `invalidSlottedTag()` from `src/utils/` |
