<mud-date-picker>

Renders inline (no trigger/popover). value is a string in single mode and an array in range/multi — array values must be set via JS property.

Modes

single · value="2026-05-15" (attribute)
range · preselected via rangeStart/rangeEnd
multi · value=[…] via JS property

Breakpoints

desktop
docked
mobile (drag handle)

Locale (Intl-driven labels)

ru-RU
en-US · week starts Sunday
ar-EG (RTL bidi check)

Edge cases

min/max constrain navigation + disable out-of-range days
far-future month (2099) · hide-today-shortcut
disabledDates (holidays) marked unselectable
