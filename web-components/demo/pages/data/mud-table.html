Edge cases

Empty table (rows = []) — built-in default empty state.

No columns / no rows at all (both props unset) — renders an empty shell with only the default empty row.

20+ rows, a very long unbroken cell value, a right-aligned numeric column, diacritics + special chars (& < > " ') and an emoji. Scroll horizontally and vertically.
