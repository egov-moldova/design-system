<mud-time-picker>

Renders inline (no trigger/popover) — <mud-time-input> opens it in a dropdown. Each column is a listbox: Up / Down, Home / End, Left / Right between columns, Enter / Space to pick.

Values

no value
value="11:15"
last hour and minute

Edge cases

min="08:30" max="17:15" · out-of-range options inactive
custom accessible labels (en)

Events

pick an hour, then a minute
