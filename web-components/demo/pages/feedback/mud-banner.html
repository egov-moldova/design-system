<mud-banner>

Full-width system message for the top of a page. variant picks the color family — info, warning or error (there is no success); emphasis picks the surface — subtle (tinted) or strong (filled). Placement and removal belong to the consumer: a dismissible banner only emits mudDismiss.

Tab reaches the link, then the close button; both draw the focus ring on every fill.

Icon

Your appointment is confirmed for 15 April. Icon supplied through the icon-start slot.
icon-name overrides the per-variant default; the slot overrides both.

Edge cases

Very long message: starting on 15 April, submitting applications for identity documents is done exclusively by online appointment, and the physical counters will serve urgent cases only.
In a narrow container the text breaks over several lines.
A long message keeps clear of the close button; below 640px the banner switches to the mobile layout.
