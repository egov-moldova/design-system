Variant: simple (position bottom)

Variant: detailed (position top, pre-expanded)

expanded set so the category list (necessary / analytics / marketing defaults) renders without a click. Anchored to the top of the box.

Custom category catalogue (JS property)

categories is an array prop — it can't be set via HTML attribute; it must be assigned as a JS property after the element upgrades. Demonstrates the real consumer pattern.

Edge cases

Overridden labels + long custom body (diacritics) to probe wrapping. Triggerable expand via the "Personalizează" button inside the banner.
