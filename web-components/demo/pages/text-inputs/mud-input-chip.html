<mud-input-chip>

chips is a string[] prop — Stencil only deserializes string/number/boolean attributes, so it MUST be set as a JS property after the element is defined (see co-located scripts).

Variants & prefilled chips (prop-driven)

default + prefilled
destructive + invalid + error-text

Sizes

md
lg

Validation & limits

max-chips=3 (input disabled at limit)
validate-pattern (email)
custom separators

States

disabled
readonly
required + empty

Edge cases

15+ chips wrapping
single very long chip
diacritics + special + emoji + RTL
empty array
